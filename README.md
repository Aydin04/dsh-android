# 📱 DSH Mobile (DeepSeek Harness Android Client & Local Agent)

Mobile Companion and Autonomous Android Agent for **DeepSeek Harness (DSH)**.

---

## ✨ Features

- 🌐 **Dual-Node Architecture**: Connect to a Remote VPS Node via Web API or run commands on Local Storage.
- ☰ **Mobile-Optimized Dashboard**: Modern UI with Hamburger Drawer Navigation, Bottom Sheet Model Picker, and Live Task Checklist.
- 🛡️ **Full System Permissions**:
  - `MANAGE_EXTERNAL_STORAGE` (All Files Access) for creating and editing projects directly in `/sdcard/Projects/`.
  - Voice Recording & Speech Recognition.
  - Camera & Multimodal Vision Ingestion.
  - Background Service (No-Doze execution).
  - Shizuku & Root privilege bridge.

---

## 🛠️ Automated APK Build (GitHub Actions)

Every push to `main` automatically compiles and packages the Android APK via **GitHub Actions**.

You can download the compiled APK from the **[Actions Tab / Releases](https://github.com/Aydin04/dsh-android/releases)**.
